# Vibe Coding 全栈开发实战课 (完结)，AI 全能开发 Vibe Coding + 智能体课程

本套完结实战课，主打**Vibe Coding 人机即兴开发 + 智能体工程化落地**，先用自然语言驱动编码 Agent 快速搭建产品原型，再叠加 SDD 规范、Harness 安全护栏，把 Demo 升级为可长期维护、能够商业上线的全栈 AI 应用，无缝接入 DeepAgents、MCP、A2A、Skills 多智能体生态，适合独立开发者、创业者、前后端工程师。

## 阶段 1｜Vibe Coding 核心工作流与人机协作

- Vibe Coding 底层理念：意图驱动开发，用自然语言描述需求、页面交互、接口逻辑，由 AI 编码 Agent 完成新建文件、编写代码、读取报错、持续迭代修复
- 区分原型快速验证和正式工程开发，认清原生 Vibe Coding 痛点：需求仅存在对话记录、架构随迭代腐化、大模型幻觉容易产出危险代码
- 训练高质量指令描述技巧，学会限定技术栈、模块边界、约束条件、验收标准，减少无效代码与幻觉问题
- 上手基础小项目，练习：下达需求 → 执行运行 → 查看报错 → 反馈迭代的闭环开发模式

## 阶段 2｜全栈技术栈实战：React19 + Elysia+Bun

- React19 前端：搭建 Agent 任务看板、大模型流式对话界面、参数配置面板、任务日志可视化页面，处理组件状态、异步请求，和后端联调
- Elysia+Bun 后端：高性能 API 服务，实现大模型接口转发、用户会话管理、数据持久化、权限校验、中间件异常处理
- 数据库对接，存储对话记录、任务状态；基础 RAG 知识库能力开发

## 阶段 3｜Vibe Coding 结合 SDD 规范 + Harness 护栏（课程重点）

- SDD 规范先行：原型验证通过后，编写结构化项目契约，锁定目录结构、模块划分、数据模型、接口契约、验收标准、高危操作黑名单，需求变更必须先更新 SDD
- Harness 受控沙箱：Agent 所有文件修改、命令执行在隔离环境运行；高危操作触发人工审批，完整审计日志，支持项目快照一键回滚，抑制幻觉带来的破坏性改动
- 从纯即兴 Vibe Coding，升级成「Vibe 做原型，SDD 定契约，Harness 控风险」的标准化工程开发流程

## 阶段 4｜Vibe Coding 接入多智能体集群

将编码能力嵌入超级 Agent 体系：

- DeepAgents 任务编排：拆解复杂产品任务，分配给规划、编码、测试、评审 Agent
- MCP：封装文件系统、数据库、向量库、第三方 API，作为智能体统一调用总线
- A2A：Agent 之间互相传递代码工件、任务状态、测试结果，异构智能体协同作业
- Skills：封装代码校验、类型检查、SDD 合规审查等可复用技能模块

## 阶段 5｜DevOps 容器部署、持续迭代

- Docker 镜像打包前后端项目，编写 Dockerfile
- CI/CD 自动化流水线、灰度发布、日志与指标监控
- 对接 AIOps，线上异常自动告警、智能故障诊断
- 产品迭代闭环：收集线上反馈→更新 SDD→驱动 Agent 重构代码→测试发布

## 阶段 6｜综合全栈实战项目

从零完整开发一款多 Agent Web AI 应用：

1. 自然语言描述产品创意，Vibe Coding 快速搭建可运行原型验证想法
2. 撰写 SDD 项目规范，划定模块边界、验收标准与风险黑名单
3. 搭建 Harness 沙箱环境，接入 DeepAgents 多 Agent 集群
4. 多 Agent 协同开发 React19 前端、Elysia 后端，自动生成测试用例
5. 代码评审、联调测试、容器化部署上线，建立迭代维护机制

## 适合人群

独立开发者、创业者、前端 / 后端工程师，想借助 AI 快速开发 AI 应用产品；
前置：基础 TypeScript/JavaScript，有基础 Web 开发经验更佳。

## 能力边界

Vibe Coding 擅长创意原型、中小型 AI 应用、内部工具快速落地；大型企业核心系统，仍然需要人工架构评审。大模型幻觉无法根除，数据库、权限、资金等高风险业务代码，必须人工终审，不可完全交由 Agent 自主执行。
